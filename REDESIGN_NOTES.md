# Premium V2 direction

This version deliberately preserves the original dark premium visual system and upgrades positioning, proof, and project storytelling.

## Main changes
- Hero repositioned around Full-Stack / SaaS / Mobile / AI while preserving the original portrait, grid, arcs, motion, and premium navigation.
- About copy reframed around product engineering and real business workflows; fake performance telemetry replaced with meaningful delivery states.
- Skills panel now reflects the current stack (Laravel, React, Flutter, FastAPI, Python, PostgreSQL, Firebase, Supabase, etc.) and removes invented speed/version claims.
- Selected Work rebuilt around JARVIS, CEFRise, and Preventive Maintenance with real portfolio visuals and case-study drawers.
- Contact copy now speaks to SaaS, web, mobile, and AI work rather than only frontend/React work.
- Internal project links and confidential operational details are intentionally not exposed.

## Run locally
npm install
npm run dev

## Build note
The source was edited in a Linux sandbox. The bundled node_modules from the original upload were removed because native optional dependencies were platform-specific. Run `npm install` on your machine before `npm run dev` / `npm run build`.
